# Prompts para imagens da Dobra 4

Use estes prompts para gerar imagens novas para cada step da seção "Como funciona" do crminer. Mantenha todas no mesmo estilo para a página parecer coesa.

## Direção visual geral

Formato recomendado: horizontal, 16:10 ou 4:3, alta resolução.

Estilo: fotografia editorial premium, realista, iluminação natural suave, composição limpa, fundo sofisticado, varejo moderno brasileiro, tecnologia sutil, sem parecer banco de imagem genérico.

Paleta: branco, grafite, preto suave, amarelo/dourado como detalhe discreto. Evitar tons muito azuis, roxos ou futuristas.

Não incluir textos legíveis, logos falsos, marcas famosas, interfaces com palavras reais ou elementos com direitos autorais.

As imagens devem deixar espaço visual para cards/overlays da landing page, especialmente no canto inferior esquerdo e canto superior direito.

## Negative prompt geral

```text
texto legível, logos, marcas famosas, interface com palavras reais, watermark, aparência de stock photo genérica, excesso de neon, estilo futurista exagerado, cores roxas ou azuis dominantes, pessoas artificiais, mãos deformadas, smartphone distorcido, dentes ou tema odontológico, hospital, jaleco médico, baixa resolução, imagem escura demais, bokeh exagerado.
```

## Prompt curto para manter consistência

Use esta frase no fim de todos os prompts se quiser reforçar unidade visual:

```text
same premium editorial visual system, clean modern retail technology aesthetic, soft natural lighting, white graphite black and subtle golden yellow accents, no readable text, no logos
```
